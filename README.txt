BANK ACCOUNT OPENING FORM
==========================

Files
-----
index.html : Form structure and HTML5 validation attributes
style.css  : Responsive styling using CSS3
README.txt : This guide

How to run
----------
1. Extract the ZIP file.
2. Open index.html in a modern web browser.
3. Fill in the form. Required fields and format constraints are validated by the browser.
4. Use Reset form to clear the entries.

Notes
-----
This is an educational front-end demo. The form uses action="#" and does not send or store
information. A real banking application would require a secure backend, server-side validation,
authentication, and appropriate privacy/security controls.
